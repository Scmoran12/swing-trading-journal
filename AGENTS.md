# Swing Trading Journal

Use the project agent definitions described in [AGENTS_ROLES.md](AGENTS_ROLES.md) when the user requests a specialist or team delegation. Assign bounded tasks and explicit deliverables; coordinate shared-file edits to avoid conflicts. Do not launch all roles automatically for a simple change.

Keep financial formulas explicit and reproducible. Distinguish user requirements, assumptions, observed data, and generated interpretations. Never invent trade records or market results. Verify changes with checks appropriate to their impact and report any unrun checks.
